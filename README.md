## 📊 Часть 1. Матрица корреляций

### Предобработка данных

Перед построением матрицы данные были подготовлены:
- удалены нечисловые столбцы (`Name`, `Ticket`, `Cabin`)
- пол и порт отправления закодированы числами (`male -> 0`, `female -> 1`)
- пропуски в возрасте заполнены медианой
- добавлены признаки `FamilySize = SibSp + Parch` и `IsAlone`

### Тепловая карта

![Матрица корреляций](/Titanic-model/titanic_correlation.png)

Матрица показывает линейную связь между каждой парой признаков. Значение от **−1** (синий, обратная связь) до **+1** (красный, прямая связь).

### Ключевые корреляции с выживаемостью

| Признак | Корреляция | Интерпретация |
|---|---|---|
| **Sex** | +0.54 | Пол — сильнейший фактор. Женщины выживали в 74% случаев против 19% у мужчин |
| **Pclass** | −0.34 | Пассажиры 1-го класса выживали втрое чаще, чем 3-го |
| **Fare** | +0.26 | Цена билета коррелирует с классом и выживаемостью |
| **IsAlone** | −0.20 | Одиночки выживали реже: без семьи сложнее пробиться к шлюпкам |
| **Age** | −0.06 | Почти нет линейной зависимости |

> **Вывод:** матрица корреляций выявляет линейные зависимости. Пол и класс билета — главные факторы выживания.

## 🤖 Часть 2. Модель машинного обучения (ML)

### Подход

Обучены две модели на признаках `Pclass, Sex, Age, Fare, Embarked, FamilySize, IsAlone, Title`.  
Данные разделены: **80% — обучение**, **20% — тест** (с сохранением пропорций классов через `stratify`).

Предобработка реализована через `Pipeline` + `ColumnTransformer`:
- числовые признаки: заполнение медианой -> `StandardScaler`
- категориальные: заполнение модой -> `OneHotEncoder`

### Модели

> MLP обучена для сравнения с GBM
 
| Модель | Описание |
|---|---|
| **Gradient Boosting** | Ансамбль деревьев, каждое следующее исправляет ошибки предыдущего |
| **MLP (нейросеть)** | Два скрытых слоя (100 + 50 нейронов), активация ReLU, оптимизатор Adam |

### Результаты

| Метрика | Gradient Boosting |
|---|---|
| **Точность (Accuracy)** | **82.7%** |
| **AUC** | **0.837** |

### Матрица ошибок

![Матрица ошибок](/Titanic-model/confusion_matrix.png)

- **99** пассажиров верно классифицированы как погибшие (TN)
- **49** пассажиров верно классифицированы как выжившие (TP)
- **11** погибших ошибочно предсказаны как выжившие (FP)
- **20** выживших ошибочно предсказаны как погибшие (FN)

### ROC-кривая

![ROC-кривая](/Titanic-model/roc_curve.png)

AUC = **0.837** означает, что модель с вероятностью 83.7% присвоит случайно выбранному выжившему более высокую вероятность выживания, чем погибшему. Для сравнения: случайное угадывание даёт AUC = 0.5.

### Метрики по классам

![Метрики классификации](/Titanic-model/metrics_heatmap.png)

![Сравнение Precision, Recall, F1](/Titanic-model/metrics_bar.png)

| Класс | Precision | Recall | F1-score |
|---|---|---|---|
| **Не выжил (0)** | 0.832 | 0.900 | 0.865 |
| **Выжил (1)** | 0.817 | 0.710 | 0.760 |

- **Precision (Не выжил) = 0.832**: предсказывая гибель, модель права в 83% случаев
- **Recall (Выжил) = 0.710**: из всех реально выживших модель находит 71%
- Модель лучше распознаёт погибших, чем выживших — это объясняется дисбалансом классов в датасете (62% погибших против 38% выживших)

## 📌 Итоговые выводы

Анализ данных и построение модели подтверждают исторически известные факты о крушении:

1. **Пол** — решающий фактор: женщины выживали в 3.9 раза чаще мужчин
2. **Класс билета**: пассажиры 1-го класса имели доступ к шлюпкам в приоритете
3. **Социальный статус** (признак `Title`) — один из сильнейших предикторов модели
4. **Одиночки** выживали реже, чем пассажиры с семьёй небольшого размера

Модель на основе Gradient Boosting достигает точности **82.7%** и AUC **0.837**, уверенно превосходя случайное угадывание и демонстрируя устойчивый результат при кросс-валидации.
