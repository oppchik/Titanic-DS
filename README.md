# Анализ выживаемости пассажиров «Титаника» и построение модели машинного обучения

Репозиторий содержит учебный проект по курсу «Введение в инженерную деятельность» (2 семестр). Цель работы — провести  анализ данных , выявить закономерности с помощью матрицы корреляции и обучить базовую модель ML для предсказания выживаемости пассажиров.

## 🛠️ Стек
* **Среда разработки:** Jupyter Notebook
* **Язык программирования:** Python
* **Основные библиотеки:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

 
## 📂 Структура репозитория
 
```
├── titanic.csv                  # Исходный датасет
├── titanic_analysis.png         # Изображение графиков по датасету
├── titanic_correlation.ipynb    # Предобработка данных + матрица корреляций + графики
└── titanic_correlation.png      # Изображение матрицы корреляции
```
 
 
## 📊 Матрица корреляций
 
### Предобработка данных
 
Перед построением матрицы данные были подготовлены:
- удалены нечисловые столбцы (`Name`, `Ticket`, `Cabin`)
- пол и порт отправления стали числами (`male -> 0`, `female -> 1`)
- добавлен признак `FamilySize = SibSp + Parch`

![Матрица корреляций](/Titanic-model/titanic_correlation.png)
 
Матрица показывает линейную связь между каждой парой признаков. Значение от **−1** (синий цвет, обратная связь) до **+1** (красный цвет, прямая связь).
> **Вывод:** пол и класс билета — главные факторы, определявшие шансы на выживание.
